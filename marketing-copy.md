## Posting tips

1. Attach a real screenshot from the site carousels every time.
2. On Reddit: read the room; helpful “I built this” beats hard sell.
3. Suggested order: **Time Bridge** (free) → **DitCopy** (film/photo groups) → **Bit Q Pro** (carefully).
4. When prices change, update this file and `prices.json` together.

## Suggested 30-day rhythm

- Week 1: Time Bridge X post + App Store text refresh
- Week 2: DitCopy post in one film/photo community
- Week 3: Studio philosophy post linking the site
- Week 4: Share a real review quote (with credit) + product link
